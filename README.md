# Ruta Leonida

Guía de fans **no oficial** de GTA 6 en español. Sitio estático sin framework: `node build.mjs` genera `dist/` a partir de `content/*.md` (páginas fijas con front matter JSON) y `data/` (hubs y entradas).

- `npm install` y `node build.mjs`; `node scripts/og.mjs` regenera imágenes OG y favicons.
- Contenido nuevo: ver `updater/README.md`.
- Despliegue: `updater/publish.sh` (GitHub Pages, rama `gh-pages`).

No afiliada con Rockstar Games ni Take-Two Interactive. Todo el arte es propio.
